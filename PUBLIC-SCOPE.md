# Public repository scope

This is a deny-by-default, static promotional showcase. It is not a production-source mirror.

## Included
- Newly authored presentation code and synthetic residential examples.
- Public brand name and official website links.
- The user-approved Fort Worth Quality Roofing logo, re-encoded without metadata.
- Screenshots of this public showcase only, reviewed and re-encoded.
- Generic contributor, architecture, security, and design documentation.
- Locked dependencies needed to build and lint the static app.

## Excluded
No production Git history, environment files, credentials, account identifiers, lead forms, route handlers, server actions, customer data, reviews, customer property photos, analytics, advertising tags, webhooks, email or telephony code, deployment connections, private paths, logs, exports, or internal planning documents.

Commercial services are not promoted in this showcase.

## Review boundary
Every repository file must appear in the safety script's exact allowlist. All media must appear in the checksum-locked asset manifest. A matching checksum proves integrity, not ownership; any new media still needs an explicit rights review.

Before publication, inspect the staged file list, run the working-tree and index safety checks, scan the complete Git history with an independent secret scanner, and verify the exported site. Never copy a production directory wholesale.
