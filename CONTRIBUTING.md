# Contributing

Read PUBLIC-SCOPE.md first. Keep changes small and presentation-only.

Run `npm ci`, `npm run safety`, `npm run lint`, `npm run build`, and `npm audit --audit-level=high`. Review staged contents with `npm run safety -- --staged` before committing.

Never include customer records, credentials, environment values, deployment details, production code, or unapproved media in issues, pull requests, or commits. Report sensitive findings through SECURITY.md.
