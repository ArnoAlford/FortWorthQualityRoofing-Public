# Public showcase rules

This repository is presentation-only. Read PUBLIC-SCOPE.md before changing it.
Never introduce production source, private data, environment files, server actions, route handlers, analytics, integrations, or copied Git history.
New files require review and inclusion in the exact allowlist in scripts/check-publication-safety.mjs.
New assets require rights approval, metadata stripping, and an updated asset-manifest entry.
Use the installed Next.js documentation before changing framework behavior.
Run safety, lint, build, and dependency audit before a change is published.
