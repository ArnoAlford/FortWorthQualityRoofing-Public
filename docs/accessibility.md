# Accessibility

Semantic headings and landmarks, a skip link, visible keyboard focus, native disclosure elements, readable contrast, and responsive single-column layouts support access.

The approved brand image has useful alt text where informative and empty alt text next to the redundant brand name. Links describe destinations. Motion is limited to a short hover color transition, removed for reduced-motion preferences.

Before publishing UI changes, test keyboard navigation, expanded disclosures, 390px and desktop layouts, zoom, and horizontal overflow.
