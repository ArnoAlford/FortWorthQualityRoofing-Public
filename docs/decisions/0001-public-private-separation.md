# Decision: independent public showcase

Status: accepted for this repository.

Follow the narrow public-showcase pattern of the ArcVelocity and HailKing references. Create new presentation code with a fresh Git root; never clone or mirror the production repository.

The only production-origin file permitted is the explicitly approved logo after metadata-stripping re-encoding. Screenshots come from the public showcase. The consequence is a smaller demonstration rather than a runnable production copy, with no access to production services.
