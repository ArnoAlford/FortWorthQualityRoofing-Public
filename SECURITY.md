# Security policy

This static showcase has no authentication, data collection, or production service integration.

## Private reporting
Use GitHub private vulnerability reporting on this repository. Do not open public issues containing suspected secrets, private information, or exploit details. Include only the minimum redacted evidence needed to locate the problem.

If exposure is suspected, treat public data as already copied: revoke or rotate affected credentials, remove the material from all refs, and coordinate cleanup privately. Do not publish credential values or fingerprints in reports.

Automated checks reduce risk; they do not replace review or guarantee that every possible secret format will be recognized.
